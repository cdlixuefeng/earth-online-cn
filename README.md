# 地球 online（国服公测版）

> 每年约 **971.5 万个**婴儿在中国出生。你将成为其中一个。
> 生在哪个省、城市还是农村，你无法选择。

一个以**真实统计数字为地基**的中文人生模拟网页游戏：从出生在中国地图上的某个角落开始，走过读书、挣钱、结婚、写信、生子，直到衰老与离世。它不是罗列随机事件的电子彩票——每件事的每年概率，都由你的出身、选择、属性和人生伏笔层层修正。

## 核心玩法

```mermaid
flowchart LR
    A[出生<br/>地图选省份] --> B[家庭<br/>十级出身]
    B --> C[成长<br/>教育 · 属性]
    C --> D[收入<br/>职业 · 职级 · 省份]
    D --> E{婚姻}
    E -->|情书 · 择偶| F[家庭<br/>伴侣 · 子女]
    F --> G[人生事件<br/>循环到老]
    G --> H{离世}
    H -->|是| I[终局<br/>黑白 · 一生回顾]
    H -->|否| G
```

一条命的时间线大致是：**出生 → 家庭 → 成长 → 挣钱 → 婚姻 → 人生事件（每年推进）→ 离世**。玩法上你做的不是"点击得分"，而是**在逐年推进的选择里决定一生**。

## 核心机制

### 1. 出生：你无法选择，但数据真实

- 按 **34 个省级行政区**的 **2024 年出生人口占比**在中国地图上落点，出生在哪一省、大城市 / 县城 / 农村，全部随机且带真实概率。
- 出生性别比按 **111.5**（国家卫健委 2025 公报，七普 111.3）加权，江西、海南偏高，东北、新疆接近 106。

### 2. 家庭：十级出身 + 家庭来源

家庭先在本省城镇或农村的收入分布里抽，再折算到**全国十级**。每一级都对应真实的月收入区间、大致存款和在全国的家庭份额（测算）：

| 级 | 家庭 | 月收入区间 | 存款约 | 全国家庭份额 |
|---|---|---|---|---|
| 1 | 很困难家庭 | 3,000 以下 | 0–3 万 | 15% |
| 2 | 困难家庭 | 3,000–8,000 | 0–5 万 | 35% |
| 3 | 普通家庭 | 8,000–1.5 万 | 5–10 万 | 30% |
| 4 | 小康家庭 | 1.5 万–3 万 | 10–40 万 | 13% |
| 5 | 潇洒活家庭 | 3 万–10 万 | 40–100 万 | 6% |
| 6 | 高收入家庭 | 10 万–30 万 | 100–200 万 | 0.9% |
| 7 | 小富家庭 | 30 万–83 万（年 360 万–1,000 万） | 200–500 万 | 0.1% |
| 8 | 中富家庭 | 年 1,000 万–5,000 万 | — | 0.02% |
| 9 | 巨富家庭 | 年 5,000 万–1 亿 | — | 0.002% |
| 10 | 顶级富豪家庭 | 年 1 亿以上 | — | 0.001% |

高收入档还会细分家庭**来源**：企业主 / 高管 / 房二代 / 体制内干部 / 专业人士 / 职业投资 / 双职工等——同样是老板，企业主家庭、拆迁户、高知家庭的脚本完全不同。

### 3. 成长与收入

- **学历**分档：初中及以下 → 高中/职校/专科 → 本科/211 → 硕士/985/C9，可考研。学历溢价（测算）以高中为 1：职校 1.05、专科 1.15、普通本科 1.45、211 1.7、985 1.9、C9 2.1；公务员溢价只算四成，务农、创业不看学历。学历还影响考公把握、进大厂、升职快慢与裁员风险。
- **收入**看去处（打工 / 白领 / 公务员 / 务农 / 创业）、职级和省份。
- 属性系统：**知识、人情、快乐、收入**。人情分三圈——工作/同事（Rw）、家人/伴侣（Rf）、朋友（Rp），借钱、升职、挽回关系都看对应圈子。

### 4. 婚姻：锚定七普的婚恋市场

- 初婚市场**锚定第七次人口普查**：50 岁未婚 男约 8%、女约 4%；30 岁前结婚约 72%；初婚中位 男约 29.5、女约 27.5，北京上海晚两年、农村早一点。
- **择偶梯度**：男看家底、学历、彩礼；女向上找，农村女最抢手，城镇高学历高档位女性最难"向上"。
- **彩礼**：江西、甘肃、河南、山西、安徽、福建、贵州、宁夏为高彩礼省（倍数 ×2）。
- 约 **1/7** 的人是"慢热"人群：社交圈小、不主动，遇见人和走到最后都更难。

### 5. 情书：99 封，写在一个具体的人身上

- 情书库里备了 **99 封**信（内置在 `letters-pack.js`），年龄、相识方式、年代、城乡、写信人身份都要对得上，一生里同一封不出现两次。
- 信**只写在婚前**——结婚以后不再收到任何信。
- 写信人有不同口吻：文艺、理工、土味直球、克制含蓄、幽默自嘲、少年青涩、质朴乡土、成熟稳重、异地、二婚/中年。
- 信里会填入读信人全名、写信人全名、城市、年份；出轨过的配偶只有在被原谅后，才会在回放里引用 ta 婚前写的信。

### 6. 故事引擎：没有纯随机事件

这是游戏最核心的设计原则：

> 每条事件的**年概率 = 基础值 × 你的决策 / 重心 / 属性 / 人生伏笔修正**。

选择会沉淀成"伏笔"（如多年积累的某个 tag、某段感情留下的影子），再反哺到往后的概率上。老去时画面逐渐褪色，离世时转为黑白。

## 项目结构

```
earth-online-cn/
├── index.html           # 入口：页面、出生/家庭等级/省份逻辑
├── story.js             # 故事引擎：人生事件、婚姻、出轨、情书调度
├── letters-pack.js      # 99 封情书库（内置，运行必需）
├── hark.js              # 交互与动效
├── hark.css / hark-hero.css   # 纸与墨绘本风样式
├── chinamap.json        # 中国地图数据
├── assets/
│   └── game-cover.jpg   # README 封面（真实运行截图）
└── work/                # 模拟与校准脚本（见下）
```

> 说明：仓库根目录的 `chart.js`、`datalabels.js`、`hark-charts.*`、`letters99.js` 是模板遗留的图表资产，游戏**运行时并未加载**，不影响运行，仅作为源码留档。

## 本地运行

纯静态项目，无需服务器、无任何依赖：

```bash
# 任意方式打开 index.html 即可
start index.html
```

`work/` 下的脚本用于校准与验证（需 Node.js）：

```bash
cd work
node verify.js   # 跑 5,000 次人生模拟，验证概率与分布
node fit10.js    # 拟合 10 级家庭收入分布
```

其余 `sim.js / fam.js / marry.js / odds.js / rel.js / kn.js / tier.js` 等为各机制的独立校准脚本。

## 数据来源

所有锚定数据尽量取自公开统计，并在页面内逐条标注；**部分为测算值**（如家庭收入分位曲线、学历溢价），口径如下：

- **国家统计局 2024**：城镇人均中位 49,302 元、均值 54,188 元；农村中位 19,605 元、均值 23,119 元；全国居民收入中位数 34,707 元/人；各省 2024 出生人口、城镇化率、出生率。
- **第七次人口普查**：婚姻市场、性别比、家庭结构。
- **中国统计年鉴 2025**。
- **CHFS、胡润财富报告**：家庭收入顶部 / 高净值家庭结构（企业主 53%、金领 35%、职业投资 9%）。
- **国家卫健委**：出生性别比 111.5（2025）。
- **台湾、香港、澳门**：当地统计部门 2024 年数据，部分为近似值。

> 家庭收入先在本省城镇或农村分布中抽取，再按全国十级折算；户均人口按 2.8 估算（家庭年收入 ≈ 人均 × 2.8）。
