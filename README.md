# 地球 online（国服公测版）

> 每年约 **971.5 万个**婴儿在中国出生。你将成为其中一个。
> 生在哪个省、城市还是农村，你无法选择。

一个以**真实统计数字为地基**的中文人生模拟网页游戏：从出生在中国地图上的某个角落开始，走过读书、挣钱、结婚、写信、生子，直到衰老与离世。它不是罗列随机事件的电子彩票——每件事的每年概率，都由你的出身、选择、属性和人生伏笔层层修正。

## 核心玩法

```mermaid
flowchart LR
    A[出生<br/>地图选省份] --> B[家庭<br/>十级出身]
    B --> C[成长<br/>教育 · 属性]
    C --> D[收入<br/>职业 · 职级 · 省份]
    D --> E{婚姻}
    E -->|情书 · 择偶| F[家庭<br/>伴侣 · 子女]
    F --> G[人生事件<br/>循环到老]
    G --> H{离世}
    H -->|是| I[终局<br/>一生为册 · 档案回顾]
    H -->|否| G
```

一条命的时间线大致是：**出生 → 家庭 → 成长 → 挣钱 → 婚姻 → 人生事件（每年推进）→ 离世**。玩法上你做的不是"点击得分"，而是**在逐年推进的选择里决定一生**。

## 核心机制

### 1. 出生：你无法选择，但数据真实

- 按 **34 个省级行政区**的 **2024 年出生人口占比**在中国地图上落点，出生在哪一省、大城市 / 县城 / 农村，全部随机且带真实概率。
- 出生性别比按 **111.5**（国家卫健委 2025 公报，七普 111.3）加权，江西、海南偏高，东北、新疆接近 106。

### 2. 家庭：十级出身 + 家庭来源

家庭先在本省城镇或农村的收入分布里抽，再折算到**全国十级**。每一级都对应真实的月收入区间、大致存款和在全国的家庭份额（测算）：

| 级 | 家庭 | 月收入区间 | 存款约 | 全国家庭份额 |
|---|---|---|---|---|
| 1 | 很困难家庭 | 2,000 以下 | 0–1 万 | 9.2% |
| 2 | 困难家庭 | 2,000–4,000 | 0–3 万 | 12.1% |
| 3 | 普通家庭 | 4,000–8,000 | 3–10 万 | 27.8% |
| 4 | 小康家庭 | 8,000–1.6 万 | 10–40 万 | 31.7% |
| 5 | 潇洒活家庭 | 1.6 万–4 万 | 40–100 万 | 15.0% |
| 6 | 高收入家庭 | 4 万–12 万 | 100–300 万 | 3.6% |
| 7 | 小富家庭 | 12 万–83 万（年 144 万–1,000 万） | 200–500 万 | 0.65% |
| 8 | 中富家庭 | 年 1,000 万–5,000 万 | — | 0.02% |
| 9 | 巨富家庭 | 年 5,000 万–1 亿 | — | 0.002% |
| 10 | 顶级富豪家庭 | 年 1 亿以上 | — | 0.001% |

> 2026-10-23 校准：原口径把"家庭月入 3,000–8,000"整段算作困难，全国低保出身虚高到 49%；现按真实家庭结构下调——**困难 = 家庭月入 2,000–4,000（低收入），很困难 = 2,000 以下（低保线附近）**，低保合计约 21.3%，普通 + 小康约 59.5%（家庭月入 4,000–1.6 万）。城镇低保 8.7%，农村 41.2%，与民政部低保对象（约 4% 家庭）+ 低收入家庭占比的分层一致。

高收入档还会细分家庭**来源**：企业主 / 高管 / 房二代 / 体制内干部 / 专业人士 / 职业投资 / 双职工等——同样是老板，企业主家庭、拆迁户、高知家庭的脚本完全不同。

#### 省份 × 每 100,000 个新生儿

出生卡上"在{省}：每 100,000 个新生儿 X 个"是**该省城乡新生儿加权**的档位条件概率（城镇新生儿占比 ≈ 城镇化率 − 5 个百分点）。全国与各省分布均按上述十级份额和各省收入倍率推演，梯度与公开经济数据一致（摘录）：

| 每 100,000 个新生儿出生于 | 很困难家庭（月入 <2,000） | 困难 + 很困难（<4,000） | 小康及以上 |
|---|---|---|---|
| 全国（出生加权） | 约 9,200 | 约 21,300 | 约 51,000 |
| 甘肃农村 | 约 25,800 | 约 73,200 | 约 1,200 |
| 贵州 / 云南 / 青海 | 城镇 5,300–5,600 · 农村 20,400–23,700 | 城镇 9,600–10,300 · 农村 56,800–67,700 | 城镇 61,700–69,100 · 农村 1,800–3,400 |
| 河南 / 四川 / 湖北 | 城镇 5,200–5,800 · 农村 15,000–16,600 | 城镇 9,400–10,800 · 农村 36,900–42,700 | 城镇 56,200–71,300 · 农村 8,300–12,100 |
| 湖北（城镇口径） | 约 5,200 | 约 9,400 | — |
| 广东 / 山东 / 江苏 | 城镇 4,000–4,700 · 农村 10,700–13,700 | 城镇 6,800–8,300 · 农村 22,700–31,900 | 城镇 81,200–86,700 · 农村 16,600–35,100 |
| 北京 / 上海 | 城镇 3,200 / 3,150 · 农村 7,600–8,500 | 城镇 5,300 / 5,200 · 农村 15,400–17,500 | 城镇 90,400 / 90,600 · 农村 54,100–61,800 |

> 很困难家庭（第 1 级）家庭月收入区间为 0–2,000 元，但**级内抽签设有现实下限：人均年可支配 5,000 元（家庭月约 1,167 元）**——民政部 2024 公报农村低保平均标准为 593.9 元/人·月（约 7,100 元/人·年），5,000 元约等于低保标准较低省份的兜底线，因此不会出现"人均年几十元 / 月收入显示 0 元"的失真值。

### 3. 成长与收入

- **学历**分档：初中及以下 → 高中/职校/专科 → 本科/211 → 硕士/985/C9，可考研。学历溢价（测算）以高中为 1：职校 1.05、专科 1.15、普通本科 1.45、211 1.7、985 1.9、C9 2.1；公务员溢价只算四成，务农、创业不看学历。学历还影响考公把握、进大厂、升职快慢与裁员风险。
- **收入**看去处（打工 / 白领 / 公务员 / 务农 / 创业）、职级和省份。
- 属性系统：**知识、人情、快乐、健康、收入**。人情分三圈——工作/同事（Rw）、家人/伴侣（Rf）、朋友（Rp），借钱、升职、挽回关系都看对应圈子。**健康归零时人生直接结束**（病入膏肓，当场离世），不再靠死亡概率拖沓。

**家庭资源差异：同样的分数，不同的路**：家庭条件好的孩子，成长路上处处有"保底"——小升初 / 中考没考上，家里出择校费进重点中学；高考落榜，家里安排出国读预科（学历按 985 档）或复读一年；孩子出生后爸妈来帮忙带娃，省下保姆钱；中上家庭的父母有退休金，35 岁以后逢年过节还补贴你。困难家庭则相反：读高中时可能被劝退学打工，18–50 岁要替家里填修房、看病的窟窿，父母没有退休金，每月还要往家里寄钱——穷与富的差距，贯穿整个成长线。

### 4. 婚姻：锚定七普的婚恋市场

- 初婚市场**锚定第七次人口普查**：50 岁未婚 男约 8%、女约 4%；30 岁前结婚约 72%；初婚中位 男约 29.5、女约 27.5，北京上海晚两年、农村早一点。
- **择偶梯度**：男看家底、学历、彩礼；女向上找，农村女最抢手，城镇高学历高档位女性最难"向上"。
- **彩礼**：江西、甘肃、河南、山西、安徽、福建、贵州、宁夏为高彩礼省（倍数 ×2）。
- 约 **1/7** 的人是"慢热"人群：社交圈小、不主动，遇见人和走到最后都更难。

### 5. 情书：99 封，写在一个具体的人身上

- 情书库里备了 **99 封**信（内置在 `letters-pack.js`），年龄、相识方式、年代、城乡、写信人身份都要对得上，一生里同一封不出现两次。
- 信**只写在婚前**——结婚以后不再收到任何信。
- 写信人有不同口吻：文艺、理工、土味直球、克制含蓄、幽默自嘲、少年青涩、质朴乡土、成熟稳重、异地、二婚/中年。
- 信里会填入读信人全名、写信人全名、城市、年份；出轨过的配偶只有在被原谅后，才会在回放里引用 ta 婚前写的信。

### 6. 故事引擎：没有纯随机事件

这是游戏最核心的设计原则：

> 每条事件的**年概率 = 基础值 × 你的决策 / 重心 / 属性 / 人生伏笔修正**。

选择会沉淀成"伏笔"（如多年积累的某个 tag、某段感情留下的影子），再反哺到往后的概率上。老去时画面逐渐褪色，离世时转为黑白。

**人生不是千篇一律的剧本**：幼儿期（0–5 岁）每年都有随机的成长事件——学步、第一次说话、幼儿急疹、玩具、赶集、小动物、邻居玩伴、家庭合影……事件按 2–3 年冷却轮换，投胎两次，前几年完全不一样；童年期的事件同样随机（发小、打小报告、被栽赃、秘密基地、压岁钱、小动物……年龄和内容都不固定）；生子、孩子高考、孩子结婚、孙辈出生等必经节点，每次开局也有多种随机组合的文案与结果；"春节是否回家陪父母团年"这类固定节点保留，作为人生的骨架，随机事件填充血肉。

**阶段重心不是摆设**：每个年龄段有真实的"重心"加权（学生时代读书、青年拼事业、中年顾家、老年保健康），部分事件的年概率会随当期重心浮动；没有事件发生的年份，重心会自然切换阶段。

### 6.5 结局：一生为册

离世后的回顾做成一本**人生档案**，随视口逐段浮现：

- **碑文**：墓志铭按这一生有没有被爱过、有没有守护过家人自动生成，配上署名引文；
- **人生签**：盖棺定论的一句签文（多套签面随人生底色变化）；
- **一生胶片**：婴儿到老年六个阶段的头像横向滚动，每帧带年份；
- **人生档案**：享年、一生总收入、存款最高、最低点、最终净资产（通栏，含房产）；
- **与父母那一代**：十级阶梯，出身格标"出"、终局格标"终"，上升 / 守住 / 下落用暖 / 墨 / 冷色标注区间；
- **这一生的高光** 与户籍 · 学历 · 预期寿命的轨迹行收尾。

### 7. 财富与资产：从存款到财富总额

钱不只是"存款"。游戏新增**财富总额**口径，实时显示在角色面板：

> **财富总额 ≈ 现金存款（可为负）＋ 自购房净资产 ＋ 家里给的房（市值 − 未还贷）＋ 继承的房产（市值 − 未还贷）＋ 继承现金 ＋ 家族信托现值（年分红 × 20）**

角色面板会**实时拆解这笔财富的构成**：现金、不动产（自购 / 家里给 / 继承，各自扣除未还贷）、继承现金、信托现值——哪一项没有就不显示；负债（负现金、负房产净值）会如实显示，并计入人生结局的"最终净资产"。

三条与钱深度绑定的故事线：

- **继承与赠予可能是负债**：分家产时可能分到还欠着银行的房子（价跌时甚至倒欠）；接手家里的生意，债务也一起接；家里过户的房子可能带着没还完的贷款。
- **结婚买房，父母支持**：家境越厚，结婚时父母给得越多——高净值家庭直接过户婚房，中等家庭给一笔成家钱（压箱钱）；穷人家给不起钱，就把旧物传下去。彩礼、首付资助、婚房、拆迁补偿都会直接体现在财富总额里。
- **重大疾病（含父母重病）财产骤减**：自己和父母的医疗自付按真实量级放大——穷家庭一场大病几万到几十万、可能卖房或背债；中产靠医保和积蓄扛一扛；高净值家庭有商业保险，钱上不太慌。大病后家里能兜底的（RESC 机制）会接住一部分，兜不住的负债会压到人生结局的"最终净资产"里。

## 项目结构

```
earth-online-cn/
├── index.html           # 入口：页面、出生/家庭等级/省份逻辑
├── story.js             # 故事引擎：人生事件、婚姻、出轨、情书调度
├── letters-pack.js      # 99 封情书库（内置，运行必需）
├── hark.js              # 交互与动效
├── hark.css / hark-hero.css   # 纸与墨绘本风样式
├── chinamap.json        # 中国地图数据
├── assets/
│   └── game-cover.jpg   # README 封面（真实运行截图）
└── work/                # 模拟与校准脚本（见下）
```

> 说明：仓库根目录的 `chart.js`、`datalabels.js`、`hark-charts.*`、`letters99.js` 是模板遗留的图表资产，游戏**运行时并未加载**，不影响运行，仅作为源码留档。

## 本地运行

纯静态项目，无需服务器、无任何依赖：

```bash
# 任意方式打开 index.html 即可
start index.html
```

`work/` 下的脚本用于校准与验证（需 Node.js）：

```bash
cd work
node verify.js   # 跑 5,000 次人生模拟，验证概率与分布
node fit10.js    # 拟合 10 级家庭收入分布
```

其余 `sim.js / fam.js / marry.js / odds.js / rel.js / kn.js / tier.js` 等为各机制的独立校准脚本。

## 数据来源

所有锚定数据尽量取自公开统计，并在页面内逐条标注；**部分为测算值**（如家庭收入分位曲线、学历溢价），口径如下：

- **国家统计局 2024**：城镇人均中位 49,302 元、均值 54,188 元；农村中位 19,605 元、均值 23,119 元；全国居民收入中位数 34,707 元/人；各省 2024 出生人口、城镇化率、出生率。
- **第七次人口普查**：婚姻市场、性别比、家庭结构。
- **中国统计年鉴 2025**。
- **CHFS、胡润财富报告**：家庭收入顶部 / 高净值家庭结构（企业主 53%、金领 35%、职业投资 9%）。
- **国家卫健委**：出生性别比 111.5（2025）。
- **台湾、香港、澳门**：当地统计部门 2024 年数据，部分为近似值。

> 家庭收入先在本省城镇或农村分布中抽取，再按全国十级折算；户均人口按 2.8 估算（家庭年收入 ≈ 人均 × 2.8）。
